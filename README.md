# 내 노후 계산기 (PFMS)

노후 현금흐름·세금·건강보험료를 한눈에 진단하는 정적 웹 계산기입니다.
서버·빌드가 필요 없는 **순수 HTML/JS**라 GitHub Pages 등 정적 호스팅에 바로 올릴 수 있습니다.

## 구성

| 파일 | 용도 | 대상 |
|------|------|------|
| `index.html` | **3분 빠른 진단** (단계형·신호등 결과, 모바일 최적) | 일반 사용자 |
| `simple.html` | **간편 계산기** (카드·그래프·최적화·출력/인쇄) | 좀 더 자세히 보고 싶은 사용자 |
| `pro.html` | **정밀/전문가 모드** (주택연금·의료비·배우자 사망 등 확장 시나리오) | 상세 설계 |

`index.html`의 "정밀 계산으로 더 알아보기" 버튼은 `pro.html`로 연결됩니다.

## GitHub Pages 배포

1. 새 저장소를 만들고 이 폴더의 파일(`index.html`, `simple.html`, `pro.html`, `.nojekyll`)을 업로드합니다.
2. 저장소 **Settings → Pages → Source**를 `main` 브랜치 `/ (root)`로 지정합니다.
3. 1~2분 후 아래 주소로 접속됩니다.
   - 빠른 진단(대표): `https://<아이디>.github.io/<저장소>/`
   - 간편: `https://<아이디>.github.io/<저장소>/simple.html`
   - 정밀: `https://<아이디>.github.io/<저장소>/pro.html`

> `.nojekyll` 파일은 GitHub Pages의 Jekyll 처리를 건너뛰게 해 파일이 그대로 서비스되도록 합니다.

## 로컬에서 실행

파일을 더블클릭해 브라우저로 열면 됩니다(별도 서버 불필요).

## 기술 메모

- `simple.html` / `pro.html` 은 그래프에 Chart.js(CDN)를 사용 → 인터넷 연결 필요.
- `index.html`(빠른 진단)은 외부 라이브러리 없이 독립 실행.
- 입력값은 사용자의 브라우저 `localStorage`에만 저장되며 **서버로 전송되지 않습니다.**
