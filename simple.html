내 노후 계산기

지금 자산으로 노후에 매달 얼마를 쓸 수 있고, 건강보험료·세금은 얼마이며, 돈이 언제까지 갈지 한눈에 확인하세요.

1. 내 정보

연금·저축을 꺼내 쓰기 시작하는 나이
가능=소득·재산 요건 충족 시 보험료 0원 / 불가=지역가입자로 직접 납부(소득·재산 적으면 소액)
부부 기준 한 달 목표 생활비. 물가만큼 매년 오릅니다

2. 매달 들어오는 연금

65세 기준 예상액. 일찍/늦게 받으면 자동 조정
60~70세. 빠르면 감액, 늦으면 증액
위 수령액은 '정상' 기준. 최소·미납이면 가입기간·소득 감소로 연금이 줄어듭니다(추정). 정확치는 공단 모의계산↗

3. 퇴직·개인 연금 통합연금포털 조회↗

IRP로 받은 순수 퇴직금. 세금 감면이 커서 오래 나눠 받으면 유리
내가 넣은 개인연금 (연금저축·IRP)
연말정산에서 세액공제 받은 납입금 → 인출 시 연금소득세(저율 3.3~5.5%)
연 900만원 한도 초과 납입분 → 인출 시 비과세. 없으면 0
운용으로 늘어난 수익 → 인출 시 연금소득세(저율)

4. 그 밖의 소득 (연간)

월세 등. 세금 내는 임대소득만(1주택 비과세면 0)
예금 이자, 주식 배당 등. 연 1,000만원 넘으면 건보료에 반영

5. 재산·자산

공시가격의 약 60%. 건강보험료(지역) 계산에 사용
세입자인 경우만. 보증금의 30%가 재산에 반영
꺼내 써도 세금 없음
수익만 저율(9.9%) 과세
종류별로 여러 개 추가 가능 · 국내주식 비과세, 해외주식 22%(연250만공제), 배당·펀드 15.4% · 수익(잔액−원금)에만 과세
